# 01 — Global Style Board Prompt (Variant AI)

## Prompt

```
Design a comprehensive style board for a premium birth-data pattern analysis web app called "Momentor".

PRODUCT CONTEXT:
Momentor analyzes birth date patterns to generate precision personality and forecast reports. It is NOT an astrology app, NOT a fortune-telling app, NOT an Eastern philosophy learning tool. Think of it as a Bloomberg Terminal meets personality analytics — data-driven, precise, premium.

TARGET AUDIENCE:
Western users (US/EU), ages 25–40, who appreciate design-forward tools. They pay for insight, not mysticism.

BRAND POSITIONING:
"Your birth data holds patterns. We decode them."
— Scientific confidence, not spiritual promise
— Premium software, not wellness app
— Restrained luxury, not maximalist mystique

COLOR SYSTEM:
- Background: #0d0b1e (deep space black with subtle purple undertone)
- Surface 1: #110f27 (elevated cards)
- Surface 2: rgba(255,255,255,0.04) (card fills)
- Border: rgba(255,255,255,0.08) (subtle separation)
- Gold Primary: #c9a96e (restrained, used sparingly for accents and CTAs)
- Gold Light: #dfc08a (hover states, active elements)
- Gold Soft: rgba(201,169,110,0.75) (secondary emphasis)
- Gold Dim: rgba(201,169,110,0.35) (tertiary, labels)
- Gold Tint: rgba(201,169,110,0.08) (background tints)
- Text Primary: rgba(255,255,255,0.92)
- Text Secondary: rgba(255,255,255,0.68)
- Text Muted: rgba(255,255,255,0.48)
- Element colors (used in data viz only, never dominant):
  - Green: #4ade80
  - Red-pink: #f87171
  - Amber: #d97706
  - Silver: #94a3b8
  - Blue: #60a5fa

TYPOGRAPHY:
- Display/Headings: Cormorant Garamond (weights 300, 400, 500, 600)
  — Used for: hero titles, section headers, reading titles, pull quotes
  — Style: editorial, refined, high contrast
- Body/UI: Inter (weights 300, 400, 500, 600)
  — Used for: body text, labels, buttons, inputs, navigation
  — Style: clean, legible, modern

TYPE SCALE:
- Hero title: 48–64px (serif, weight 300–400)
- Section title: 28–36px (serif, weight 400)
- Card title: 20–24px (serif, weight 500)
- Body: 16px (sans, weight 400, line-height 1.7)
- Caption/Label: 13–14px (sans, weight 500, letter-spacing 0.04em, uppercase)
- Button: 15px (sans, weight 600)

SPACING:
- XS: 8px | SM: 16px | MD: 24px | LG: 32px | XL: 48px | 2XL: 64px

RADIUS:
- Small (inputs, pills): 8px
- Medium (cards): 12px
- Large (modals, hero elements): 16–20px

COMPONENT STYLE RULES:
1. Cards: Surface 2 fill + Border color + 12px radius. No drop shadows. Subtle inner glow on hover (gold-tint).
2. Buttons (Primary): Gold fill (#c9a96e), dark text (#0d0b1e), 8px radius, 15px Inter 600. Hover: Gold Light.
3. Buttons (Secondary): Transparent, gold border, gold text. Hover: gold-tint fill.
4. Inputs: Surface 2 fill, border color, 8px radius. Focus: gold border glow.
5. Dividers: 1px solid rgba(255,255,255,0.06). Never heavy.
6. Tags/Pills: Gold-tint background, gold-dim text, 20px radius, 13px uppercase.
7. Icons: Thin stroke (1.5px), monochrome white or gold. No filled icons.

MOTION PRINCIPLES:
- Entrance: fade-up, 400ms ease-out, staggered 80ms per item
- Hover: 200ms ease transitions
- Page transitions: crossfade 300ms
- Loading: orbital rotation, smooth infinite

IMAGERY / VISUAL LANGUAGE:
- Abstract orbital diagrams (NOT zodiac wheels, NOT bagua, NOT mandala)
- Thin-line geometric patterns suggesting data connections
- Radial compositions implying system analysis
- Subtle particle effects on dark backgrounds
- NO: Chinese/Japanese/Korean characters visible in UI
- NO: Five-element color wheels or tables
- NO: Yin-yang symbols, trigrams, or traditional Eastern motifs
- NO: Crystal, tarot, zodiac, or Western mystical imagery either

LAYOUT PRINCIPLES:
- Max content width: 680px (reading content), 1200px (hero/feature sections)
- Single-column for reading flow
- Generous whitespace (minimum 48px between sections)
- Left-aligned text (no centered paragraphs except hero)
- One primary CTA per viewport

TONE OF VOICE (for placeholder text):
- Confident but not arrogant
- Precise but not clinical
- Intriguing but not mystical
- Examples:
  - "Patterns decoded from your birth data"
  - "Your analytical profile is ready"
  - "See what the data reveals"
  - NOT: "Discover your destiny" / "Ancient wisdom" / "Your cosmic blueprint"

DELIVERABLE:
Create a style board showing:
1. Color palette with all tokens
2. Typography samples (all weights, sizes, both fonts)
3. Button states (primary, secondary, disabled, hover)
4. Input field states (default, focus, filled, error)
5. Card component (default, hover)
6. Tag/pill component
7. Icon style samples (6-8 thin-line icons)
8. A sample abstract orbital/radial motif that could serve as brand signature
9. Spacing and grid demonstration

Format: 1440×1024 canvas, dark background, organized in a clean grid layout.
```
