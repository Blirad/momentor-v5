# Momentor App Redesign — UltraPlan for Variant AI

## Overview

**Product**: Momentor.app — Precision pattern analysis tool based on birth data
**Targets**: Western-market users (US/EU primary)
**Platforms**: PC (1440px) + Mobile (390px), separate designs, shared tone
**Tool**: Variant AI for all design generation

## Pricing Architecture (New)

| Tier | Name | Price | Content |
|------|------|-------|---------|
| Free | Prologue | $0 | Birth pattern summary, element composition, identity keywords |
| Paid Main | Full Reading | $15.99 | Complete 2026 forecast, 10 life domains, monthly flow, today's energy |
| Paid Sub | Compatibility Reading | $12.99 | Two-person pattern overlay, relational dynamics, timing windows |

**Removed**: Bundle, Early Bird, AI MVP, Daily subscription

## Design Principles

- Dark base (#0d0b1e) + restrained gold (#c9a96e)
- Editorial serif (Cormorant Garamond) + clean sans (Inter)
- Premium software feel — not mystical, not educational
- One clear action per screen
- No Hanja characters, no textbook diagrams, no Five-Element tables, no learning-oriented layouts
- Eastern system = backend engine only; frontend = intuitive analytical tool

## Screen Sequence

```
1. Global Style Board
2. PC Hero
3. Mobile Hero
4. Input Flow (PC + Mobile)
5. Result Entry / Loading → Summary
6. Free Reading (Prologue)
7. Paywall → Full Reading Gate
8. Compatibility Reading Offer
9. My Readings (History/Library)
```
