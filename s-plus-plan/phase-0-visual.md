# Phase 0 — 비주얼 시스템 & 문양 (가장 중요)

## 0-1. 히어로카드 일러스트 활성화

현재 상태: 프롤로그 히어로카드에 검(Metal+Fire), 산성(Earth) 등 thin gold line art가 있지만 정적이고 평면적.

### 개선 방향

**A. SVG 일러스트 애니메이션화**

각 원소 조합별 시그니처 일러스트를 다음과 같이 활성화:

검 (Blade Forged in Noon Fire — Metal+Fire):
- 검날에 stroke-dasharray 애니메이션 → 검이 "그려지는" 느낌 (1.5초)
- 검날 위 미세한 불꽃 파티클 3-5개 (CSS or Canvas)
- 동심원 가이드가 천천히 회전 (30초/1회전, opacity pulse)
- 검 중심축에 gold glow pulse (4초 주기 breathing)
- 호버 시: 검날 glow 강화 + 동심원 회전 가속

산성 (Dragon's Iron Citadel — Earth):
- 삼각형이 아래에서 위로 stroke 애니메이션으로 세워짐
- 산맥 실루엣에 parallax 미세 이동 (마우스 반응)
- 성문 부분에 미세한 빛 pulse
- 동심원 가이드 회전 (검과 동일 방식)
- 호버 시: 산맥에 mist/fog 효과 (gradient opacity 변화)

**B. 누락된 원소 조합 일러스트 신규 제작**

각 천간(10개) 또는 주요 원소 조합별 시그니처 일러스트 필요:

| 원소 | 시그니처 오브젝트 | 스타일 |
|------|-------------------|--------|
| Wood 甲 | 고목(古木) — 거대한 나무, 뿌리가 대지를 감싸는 형상 | 나무 기둥 중심 + 가지가 동심원 밖으로 뻗어나감 |
| Wood 乙 | 덩굴/담쟁이 — 나선형으로 감아 올라가는 형상 | 나선 곡선 + 작은 잎 점들 + 원형 가이드 |
| Fire 丙 | 태양/정오 — 방사형 광선 | 중심 원 + 12방향 직선 광선 + 외곽 코로나 링 |
| Fire 丁 | 촛불/랜턴 — 고요한 불꽃 | 불꽃 형상 중심 + 바람에 흔들리는 미세 애니메이션 |
| Earth 戊 | 산/요새 — (기존 산성 확장) | 삼각 피라미드 + 지층 수평선 |
| Earth 己 | 정원/밭 — 정돈된 그리드 | 수평 토지 + 작물 점 패턴 + 계절 원형 가이드 |
| Metal 庚 | 검/도끼 — (기존 검 확장) | 수직 무기 + 연마 광선 |
| Metal 辛 | 보석/결정체 — 다면체 | 팔면체/십이면체 와이어프레임 + 내부 굴절 선 |
| Water 壬 | 강/대해 — 넓은 수평 파도 | 수평 파형 3-5겹 + 깊이감 레이어 |
| Water 癸 | 이슬/안개 — 부유하는 물방울들 | 산포된 원형 점들 + 연결선 + 안개 gradient |

모든 일러스트 공통 규칙:
- Thin gold line (#c9a96e) on dark bg
- 동심원/기하학 가이드 오버레이 (현재 검/산성과 동일)
- SVG로 제작 → stroke 애니메이션 가능
- 정적 상태에서도 아름답고, 애니메이션으로 살아남
- 일러스트 크기: 카드 영역의 80% 이상 차지

**C. 카드 컴포지션 개선**

현재:
```
[일러스트 (정적)]
[Person1, you are]
[타이틀 텍스트]
[게이트 라벨]
```

개선:
```
[일러스트 (애니메이션, 카드 전체 배경)]
  ↑ 일러스트가 카드 가장자리까지 확장, 여백 없이
  ↑ 텍스트는 일러스트 위에 오버레이 (현재 유지)
  ↑ 카드 보더: 1px gold → subtle gold glow border (box-shadow)
  ↑ 카드 배경: 현재 solid dark → 미세한 radial gradient (일러스트 중심에서 발산)
```

키워드 필 개선:
```
현재: 정적 border pill
개선: 호버 시 gold-tint fill fade-in + 미세한 scale(1.03)
      등장 시: 순차 fade-up (80ms stagger)
```

## 0-2. 신규 장식 문양 시스템

Co-Star처럼 페이지 전체에 "비주얼 구두점"이 되는 장식 문양 추가.

### 문양 유형

**A. 섹션 디바이더 문양**
- 현재: 없음 또는 단순 가로선
- 신규: 가로 중앙에 작은 기하학 문양 (마름모, 작은 원형 패턴, 십자 등)
- 크기: 40-60px, gold at 30% opacity
- 섹션 간 전환마다 사용

**B. 코너 장식 (Corner Ornaments)**
- 히어로카드 네 모서리에 L자형 기하학 장식
- 얇은 금선 (0.5px), 모서리에서 20px 안쪽
- 현재 카드 보더를 보조하는 역할

**C. 배경 텍스처 패턴**
- 카드 배경에 미세한 기하학 반복 패턴 (5% opacity)
- 예: 작은 원형 도트 그리드, 또는 45도 해칭
- CSS background-image로 구현 (SVG pattern)

**D. 플로팅 심볼**
- 페이지 여백에 떠다니는 작은 기하학 심볼 3-5개
- 원소 아이콘의 초소형 버전 (16-24px)
- parallax drift 애니메이션
- opacity 0.1-0.2 — 은은한 존재감

## 0-3. 타이포그래피를 비주얼로 활용 (Co-Star 원칙)

- "THE SHAPE OF YOU" 같은 섹션 라벨: 크기 키워서 (18-24px) 시각적 랜드마크화
- 큰 따옴표(") 를 120px 크기로, 내러티브 시작 지점에 watermark로 배치 (10% opacity)
- 챕터 번호를 거대하게 (200px+, 5% opacity) 배경 워터마크로 사용 — 한문 워터마크 대체

## 0-4. 그레인/텍스처 오버레이 (Co-Star 원칙)

- 전체 viewport에 SVG 노이즈 필터 또는 CSS noise 오버레이
- opacity: 0.03-0.05 (거의 안 보이지만 물성감 부여)
- mix-blend-mode: overlay
- 화선지/필름 그레인 느낌 → 디지털 차가움 제거
