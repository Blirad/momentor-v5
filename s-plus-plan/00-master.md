# Momentor S+ Upgrade — 최종 마스터 플랜

## 전제 조건

- 한문(氣, 靜, 印 등) 전면 제거 → 영어 or 추상 비주얼로 대체
- Temporal Capture 레이아웃(잉크 워시 배경, 3패널 그리드, 부적 구조) = 기본 뼈대 유지
- 프롤로그 히어로카드 일러스트(검, 산성 등) = 핵심 자산, 활성화 필수
- Co-Star급 비주얼 트렌디함 적용
- 서양 사용자 친화적 — 동양 학습 앱 느낌 완전 제거

## Phase 구성

| Phase | 이름 | 핵심 |
|-------|------|------|
| 0 | 비주얼 시스템 & 문양 | 히어로카드 일러스트 활성화 + 신규 문양 |
| 1 | 배경 & 분위기 | Canvas 파티클 + 잉크 워시 고도화 + 그레인 |
| 2 | 중앙 시각화 | SVG 연결선 + 노드 → 영어 전환 + 축 개선 |
| 3 | 인감 의식 | 다단계 캡처 시퀀스 |
| 4 | 입장 연출 | 3초 시네마틱 시퀀스 |
| 5 | 실시간 데이터 | 라이브 시계 + 월상 + 시간대별 분위기 |
| 6 | 커서 & 사운드 | 커스텀 커서 + Web Audio 앰비언트 |
| 7 | 모바일 대응 | 반응형 레이아웃 |
